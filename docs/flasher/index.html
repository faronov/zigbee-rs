zigbee-rs web flasher

Released firmware for the ZRHP NCP (zigbee-rs as a Zigbee coordinator for zigpy/ZHA, Zigbee2MQTT and the zigbee-rs hub) and for the hub itself. Every image comes from a tagged GitHub release. Needs Chrome or Edge on a desktop (Web Serial).

This browser has no Web Serial. Use Chrome or Edge (version 89 or later) on Windows, macOS or Linux. Firefox and Safari cannot flash. The images and esptool commands are on the release pages.

4. Connect and install

    If the S3 already runs tbr-hub or tbr-bridge, its USB port shows the bridge's two serial ports instead of the S3's own USB-Serial-JTAG. Switch it over first: pick the second (console) port below. The bridge ports disappear and the USB-Serial-JTAG port appears within a second (console command s3 usj does the same). Use the new port in the next step.

    After the install: serial console and Wi-Fi setup in the browser (hub mode, Wi-Fi credentials, API token and the hub's address), on the second of the hub's two USB serial ports.

    This board comes with different flash sizes, and an image for a larger flash does not boot at all. The flasher first reads the chip's flash ID and partition table, then offers only images that fit (the largest by default). Install then uses the same port.

    Web Serial is not available in this browser: use Chrome or Edge. Web Serial needs HTTPS: open https://faronov.github.io/zigbee-rs/flasher/.

    ESP Web Tools then asks for the serial port (not for boards with a detected flash size: it uses the detected port), checks that the chip matches the board (a wrong chip is refused before anything is written), writes the images and resets the chip. Close any other program that holds the port (Zigbee2MQTT, Home Assistant, a serial monitor) first. On Windows the native USB ports use the built-in driver; no extra driver is needed.
