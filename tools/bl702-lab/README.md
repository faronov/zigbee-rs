# BL702 lab

This directory holds BL702 experiments that are not part of the supported
production HAL or product firmware.

Experiments may compile or may record a hardware result, but neither is a
production-support claim. Each experiment documents its own validation level
and remaining hardware gates.

- [`experiments/tsen`](experiments/tsen/README.md) — archived on-chip
  temperature-sensor attempt; the tested XT-ZB1 produced invalid readings.
