# RAIL HP-PA transitions (BRD4187A, GSDK 4.5.0 RAILtest, channel 26)

Decoded from `raw/sampler2.tar.xz`: `railtest-sampler/app.c` starts one
RAIL transmission (30-byte frame, `setTxTransitions idle idle`) and samples
seven registers in a tight loop (one sample per ~11 us at 39 MHz HCLK),
recording a row only when a value changes. Times are from `RAIL_StartTx`.
Requested `setPower` in deci-dBm; RAIL picks the nearest table entry. Only
the first run (`setPower 0`) sent the loaded frame: the sampler calls
`RAIL_StartTx` without refilling the TX FIFO, so the later runs sent a short
frame. The power-up and power-down order is the same in every run.

Register fields (radio configurator map, efr32xg24 revA1):

- `RAC.TX` 0xC401_3001 = TXPAENREG, TXPAENBLEEDPREDRVREG, TXPAENBLEEDREG,
  SYCHPBIASTRIMBUFTX, TXPAEN20DBMVMID, ENPAPOWER, ENPASELSLICE; 0xC3C1_F003 adds
  TXPAENRAMPCLK, TXPAENPAOUT, TXPAENPREDRVREG and bits 22..25 (10/20 dBm
  stages); 0xC3C1_C001 is the steady value (bleeders and ramp clock off).
- `RAC.PACTRL` bit 16 = TXPASLICERST, bit 10 = TXPASELPREDRVREGVDDPA,
  [15:12] TXPASELSLICE, [7:4] TXPAPOWER.
- `MODEM.PADEBUG` 0x1800 = ENMANPAPOWER | ENMANPASELSLICE.
- `RAC.PAENCTRL` bit 8 = PARAMP, bit 16 = INVRAMPCLK; `RAC.RFSTATUS` bit 0 = MODRAMPUPDONE.
